## Overview

This repository contains the SLE-4 Architecture Decision Record (ADR) and viva preparation for the 8-Puzzle Search Performance project. The ADR documents the decision to compare Breadth-First Search (BFS) and Depth-First Search (DFS), using the recorded results from SLE-2 and the search-engine structure described in SLE-3.

## Decision summary

For the documented SLE-2 test case, the recorded results were:

| Measurement | BFS | DFS |
|---|---:|---:|
| Nodes expanded | 33 | 2,927 |
| Average execution time | 0.0541 ms | 3.2204 ms |
| Goal found | True | True |

These values describe the recorded experiment only. They do not prove that BFS is always faster than DFS for every puzzle or graph.
